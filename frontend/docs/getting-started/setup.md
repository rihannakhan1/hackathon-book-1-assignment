# Setup

This guide will help you configure your development environment for the AI-Spec Driven Technical Book project.

## Environment Configuration

1. Create a `.env` file in the backend directory based on `.env.example`
2. Add your API keys and database connection strings
3. Verify your configuration by running the test commands

## Running the Application

1. Start the backend server:
```bash
cd backend
npm run dev
```

2. In a separate terminal, start the frontend:
```bash
cd frontend
npm start
```

The application will be available at `http://localhost:3000`

## Verification

Ensure that both frontend and backend are running properly by checking the console logs for any errors.
